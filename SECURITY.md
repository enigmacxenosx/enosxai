# Security Policy

Enosx Technologies welcomes good-faith reports of security issues in ENOSX AI.

## Report a vulnerability

Email **enosxtech@gmail.com** with the affected product/version, a concise description, impact, and safe reproduction steps. Do not include real user content, credentials, access tokens, or personal data. If a proof of concept requires sensitive data, describe the setup instead of sending that data.

Please allow time for triage and remediation before public disclosure. We will make reasonable efforts to acknowledge a report and coordinate a safe disclosure timeline, but this draft does not promise a response deadline or a bounty. Do not access, alter, or retain other users' data while testing.

## Scope and supported releases

This policy covers the ENOSX AI code and official distributions maintained by Enosx Technologies. Use the latest published release for testing unless the report demonstrates that an older supported release is affected. Third-party platforms, model providers, and integrations are governed by their own reporting policies.

## Publication status

This policy is a draft for review. Confirm the monitored reporting inbox, response owner, supported-version window, and incident-response process before publishing it as a commitment.
