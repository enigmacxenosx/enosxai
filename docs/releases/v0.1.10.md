# ENOSX AI v0.1.10

## Enosx Technologies installer refresh

This release gives the desktop installer a more deliberate ENOSX identity and prepares the next signed desktop build.

### Highlights

- Rebuilt the application and installer artwork from the supplied Enosx logo concept.
- Added a navy, cyan, and mint visual system across the app icon, NSIS sidebar, and installer header.
- Added clearer **ENOSX AI** and **Enosx Technologies** hierarchy to the Windows installer panels.
- Added subtle glow and signal-line details for a more polished technology-brand finish without reducing text legibility.
- Bumped the desktop shell, Tauri package, and Rust package to **0.1.10**.

### Distribution

The `Build ENOSX AI installers` workflow publishes Windows (`.msi`, `.exe`), macOS (`.dmg`), and Linux (`.AppImage`, `.deb`) bundles for the `v0.1.10` tag.
