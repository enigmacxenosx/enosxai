# ENOSX AI v0.1.12

## Chat polish and image generation

This release simplifies the chat experience and makes image generation easier to use.

### Highlights

- Removed the visible “ENOSX is thinking…” card and request-status caption from chat, while retaining screen-reader status feedback.
- Image requests such as “generate an image of a tree” now start image generation directly from the message prompt; the image-mode button is no longer needed.
- Improved compatibility with common NVIDIA image API response formats and surfaced generation errors in the conversation.
- Updated the desktop shell, Tauri configuration, and Rust package versions to **0.1.12**.

### Distribution

The `Build ENOSX AI installers` workflow builds Windows (`.msi`, `.exe`), macOS (`.dmg`), and Linux (`.AppImage`, `.deb`) bundles for the `v0.1.12` tag and attaches them to the GitHub release.
