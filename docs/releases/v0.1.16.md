# ENOSX AI v0.1.16 — Personalized replies & notifications

## Added
- Signed-in profile details and preferences (name, email, preferred language, AI personality, and theme) are included in the assistant's request context to support more relevant responses. The prompt instructs the assistant to use personal details discreetly and only when relevant.
- A completed assistant reply now appears as the body of a reply-specific system notification, truncated to a safe notification length.

## Fixed
- The synthesized EX notification sound now resumes a suspended Web Audio context before scheduling its two-tone chime.

## Notes
- Browser notification permission must be granted for system notifications.
- Browsers and operating systems may restrict sound playback, especially when the page is backgrounded; background Web Notifications use the platform's notification sound rather than a custom audio file.

## Validation
- `pnpm --filter @workspace/enosx-app typecheck`
- `pnpm --filter @workspace/enosx-app build`
