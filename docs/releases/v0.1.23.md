# ENOSX AI v0.1.23

## Engineering expertise and token usage

This release expands ENOSX AI's technical guidance and makes accumulated model usage visible in chat.

### Highlights

- Added chemical-engineering guidance for material/energy balances, reaction and separation processes, transport, scale-up, and process safety.
- Added thermodynamics guidance for open/closed-system laws, properties, phase equilibrium, equations of state, and power/refrigeration cycles.
- Strengthened AC phasor and power-balance expectations, with a reproducible complex-network regression prompt and reference solution in `docs/tests/engineering-ac-circuit-analysis.md`.
- Added a lifetime token-used count to the upper chat bar and insights dashboard. Provider totals are displayed when supported; otherwise the app uses a text-length estimate. The meter is a usage display, not a quota or limit.

### Validation

- Workspace typecheck and frontend build.
- The complex AC prompt was exercised against the deployed model. It initially swapped component assignments; after stronger instructions, a subsequent answer still reported a large KCL residual while calling the check successful. The prompt now requires rectangular arithmetic and a strict residual threshold, but this test does **not** establish reliable numerical performance. Independently verify engineering calculations before relying on them.

### Distribution

Pushing tag `v0.1.23` starts the `Build ENOSX AI installers` workflow to build Windows, macOS, and Linux bundles and attach them to this GitHub release.
